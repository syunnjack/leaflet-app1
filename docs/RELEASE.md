# SPOTPALETTE アプリ公開設定

- App name: `SPOTPALETTE`
- Expo slug: `spotpalette-app`
- iOS Bundle ID: `jp.spotpalette.app`
- Android package: `jp.spotpalette.app`
- Custom scheme: `spotpalette://`
- Universal Links: `https://spotpalette.app/place/*`, `https://spotpalette.jp/place/*`

ストア公開後に取得できるApple Team IDとAndroid署名証明書SHA-256をWeb側へ登録し、Universal Links／App Linksを有効化する。
